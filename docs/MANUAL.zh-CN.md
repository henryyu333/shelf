# ShelfU 使用说明

ShelfU 是住在 macOS 刘海里的工具：文件托盘、剪贴板、正在播放、工具卡、AI 用量和桌面小组件，都从刘海里长出来。空闲时它完全隐形；悬停或拖拽靠近刘海时先探头提示。点一下刘海，打开的是 440 × 156 的「总览」：右边是最近放入的五项，可以直接拖出去，下面一行是「当前最相关的事」；左边是状态文字和海獭。页面图标在顶栏左侧（总览、托盘、剪贴板、工具，打开 AI 用量后还有 AI 用量），点一个图标，同一个面板向下长高成 440 × 250 的页面；如果是拖着东西过来，一进入投放带就直接打开「托盘」页等着接收。每一页都是这个尺寸，所以面板停在菜单栏下面，不会盖住菜单栏和窗口。Esc 一级一级往回退：页面回到总览，再按一次收回刘海。

系统要求：Apple Silicon 芯片（M1 或更新）的 Mac，macOS 13 或以上。不支持 Intel 芯片的 Mac。

## 安装

1. 下载 [ShelfU.dmg](https://github.com/henryyu333/shelfu/releases/latest/download/ShelfU.dmg)。
2. 打开下载好的文件，把 **ShelfU** 拖到 **Applications（应用程序）** 文件夹上。
3. 从“应用程序”里打开 ShelfU。它常驻屏幕顶部的菜单栏，不在 Dock 上占图标。
4. 按 **Control + Option + 空格**（`⌃⌥Space`）打开 ShelfU 的总览，也可以单击菜单栏的托盘图标或点刘海。第一次打开时，总览里会先出现欢迎卡：把一个文件拖到刘海试试，也可以点「跳过」。

### 第一次打开：提示“未打开 ShelfU”

ShelfU 是免费软件，没有经过 Apple 公证，所以 macOS 会让你确认一次。请只对从本项目 Releases 页面下载的版本这样做。

**macOS 15 或更新**

1. 在“应用程序”里双击 ShelfU。系统提示未打开时，点 **完成**（不要点“移到废纸篓”）。
2. 打开 **系统设置 → 隐私与安全性**，往下滚动到 **安全性**。
3. 在“已阻止 ShelfU 以保护 Mac”旁边，点 **仍要打开**。
4. 输入开机密码或用触控 ID 确认，再点一次 **仍要打开**。

**macOS 13 或 14**

在“应用程序”里按住 Control 点按（或右键点按）ShelfU，选 **打开**，再在弹窗里点 **打开**。

这是只针对 ShelfU 的一次性例外，不需要关闭系统安全保护。如果系统提示 App **已损坏**，不要绕过，删掉后重新下载。Apple 官方说明：[在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。

## 日常使用

| 想做什么 | 操作 |
| --- | --- |
| 拖入文件或文件夹 | 在 Finder 拖着它往屏幕顶部中央（刘海区）移动：刘海会先探头提示，光标一进入触发区就打开「托盘」页，直接放进去；也可以拖到探头刘海上松开 |
| 摇晃唤出暂存篮 | 拖着内容时左右快速摇晃指针，光标旁浮现一张黑色篮子卡片（放到这里）；拖到上面松开即放入 ShelfU，松手后短暂显示“已放入 ShelfU”再消失。拖拽结束不放开也自动消失 |
| 探头预览 | 空手把指针移到刘海上，它会向下鼓出一个小箭头提示；正在播放时向左右各长出一小截（见「控制正在播放」）。单击提示（或两翼）打开总览 |
| 总览 | 点刘海直接到这里：右边是托盘最前面的五项（置顶的排在最前），以小格子显示——拖住就能拖进任何应用，右键是常用菜单，点一下打开「托盘」页并选中它；「全部 ›」也打开「托盘」页。左边是「托盘 N 项」「剪贴板 N 条」两行字和海獭：有任务在跑时好奇、出错时装作难过、有好消息时开心、安静十分钟后打瞌睡；任务进行中时两行字改成「正在处理 / 做完的会留在托盘」 |
| 总览的那一行 | 格子下面一行「当前最相关的事」，一次只显示一件：进行中的任务带进度条和取消按钮；出错或刚做完显示那句话；下载好的新版本显示「新版本已就绪 · 重新启动」和「重新启动」按钮；有歌时显示封面、歌名、歌手和播放暂停、下一首（点这一行打开「正在播放」）；两分钟内复制过东西时显示「刚复制：…」和「全部 ›」；都没有时显示剪贴板的条数和「打开」 |
| 欢迎卡与新功能介绍 | 全新安装后第一次展开时，总览的内容位置换成欢迎卡：把文件拖到刘海就算完成（托盘里会出现它，也会提示可以再拖出去），不想试就点「跳过」，看过一次就不再出现。更新后的第一次展开会介绍这个版本的新变化，点「好的」关掉，每个版本只出现一次；想再看，在 设置… → 关于 里点「新功能介绍」。开发构建（版本 dev）不显示更新后的介绍 |
| 控制正在播放 | 总览里正在播放的那一行就是播放器，点它打开「正在播放」页：封面、歌名和「歌手 · 应用」、已播时间 + 可拖动的进度条 + 剩余时间、上一首 / 播放暂停 / 下一首、两端带喇叭的音量条。拖进度条松手后跳转，拖音量条松手后设置系统默认输出设备的音量；设备不能调音量时音量行变暗并说明。没有在播放时显示空状态。悬停刘海时只向左右各长出一小截：左边封面，右边音频条（播放时跳动，暂停时静止），不向下遮挡窗口，也没有按钮；单击它打开总览 |
| 正在播放开关 | 设置… → 外形与提示 →「悬停刘海时」→「在刘海里显示正在播放」，或用右键菜单栏图标 →「正在播放」：启停悬停时的两翼和音乐卡片，立即生效（不必重启）；设置文件损坏时该项置灰 |
| 打开设置窗口 | 右键点菜单栏图标 → 设置…：一个带侧栏的普通窗口，所有偏好都在里面，改完立即生效 |
| 切换语言 | 设置… → 通用 → 「语言」选跟随系统 / 简体中文 / English：立即生效，不用重新打开 ShelfU；跟随系统时 Mac 的首选语言是中文就显示中文（简体、繁体都显示简体中文），其他语言显示英文；日期和时间按 Mac 的地区和 12/24 小时制显示，服务菜单里的「添加到 ShelfU」跟系统语言走 |
| 手动打开或收起 | 按 `⌃⌥Space`，或单击菜单栏图标：打开的是总览，再按一次收起 |
| 退回上一层 | 按 Esc 先回到总览，再按一次 Esc 就收回刘海；点面板外（菜单栏那一条高度以内不算）或再按一次快捷键都直接收起，不经过总览 |
| 收好复制的文字 | 正常按 `⌘C`；约半秒自动加入托盘，无需先打开面板 |
| 收好截图 | 用 `⌃⇧⌘4` 选区；**选区直到松开鼠标时继续按住 Control**，确保复制到剪贴板而不是保存到桌面 |
| 从服务菜单收进托盘 | 在 Finder 右键选中的文件或文件夹 → 服务/快速操作 → “添加到 ShelfU”；或在任意应用选中文字 → 应用菜单 → 服务 → “添加到 ShelfU”。托盘短暂显示“已放入”后自动收起 |
| 拖出文件、文字或图片 | 在托盘中拖住该项，到目标应用的接收位置松开；成功拖出后面板收起，原项默认仍保留（想让拖出去的项目自动离开托盘，见下面「拖出后从托盘移除」） |
| 拖出后从托盘移除 | 设置… → 托盘 → 打开「拖出后从托盘移除」：从托盘拖出并成功放下的项目立即从托盘消失；置顶的项目会保留；剪贴板截图只是不在托盘显示，剪贴板页仍有记录。截图和转换生成的文件会在拖出约 10 秒后才删除，让接收的应用有时间读取。从剪贴板页拖出不受影响 |
| 把一条文字复制回来 | 单击文字项，然后在编辑器等应用中按 `⌘V`；或按 `⌃⌥V` 用键盘找到它 |
| 只查看剪贴板收录的内容 | 点顶栏左侧的剪贴板图标；托盘页放文件、文件夹、图片（含剪贴板截图）以及拖入/服务收录/置顶的文字——未置顶的剪贴板文字只在剪贴板页 |
| 搜索剪贴板内容 | 按 `⌃⌥V`：「剪贴板」页直接打开、焦点在搜索框，输入即按子串筛选（大小写不敏感）；`↑`/`↓` 移动选中，`⏎` 复制选中项并收起、焦点回到你原来的应用；`Esc` 先清空搜索、再按一次收起。剪贴板里的截图和图片会在后台用本机文字识别读一遍（一次一张，不联网），图中文字也能被搜到：命中的图片第二行显示「图中文字：…」和命中的片段；还没识别完的图片暂时只在未搜索时列出 |
| 置顶项目 | 右键项目 → 「置顶」；置顶行带图钉标记、在两个标签页都排最前，不被文字限额、自动清理和「清空」移除；再右键 → 「取消置顶」还原 |
| 不再记录某个应用的剪贴板 | 右键剪贴板条目 → 「不再记录来自『应用名』的内容」；它写入 `settings.json` 的 `excludedApps`，设置文件损坏时这一项置灰 |
| 更多操作 | 右键单击项目（或按住 Control 单击）：打开、在 Finder 中显示、快速查看、隔空投送、复制文字或路径、复制图片（单张图片时）、置顶、移除。对已选中的项目右键，操作作用于全部选中项 |
| 复制图片 | 在托盘里选中一张图片后按 `⌘C`（无需先激活 ShelfU；切走页面、关闭面板或打开设置后会归还按键），或右键图片 →「复制图片」：剪贴板里是 PNG 图片数据，不是文件路径；提示「已复制图片 · 在其他应用按 ⌘V 粘贴」。文件项不变，多选时只对单张可用 |
| 识别文字并复制 | 右键一张图片（截图、剪贴板图片或图片文件）→「识别文字并复制」：已经识别过的直接复制，没有就当场识别；成功提示「已复制识别出的文字 · N 字」，文字同时记进剪贴板页（来源显示「框选文字」），没有文字时提示「没有识别到文字」。后台正在识别别的图片时会排队，完成后自动复制。全部在本机完成 |
| 框选屏幕文字 | 按 `⌃⌥O`，或右键菜单栏图标 →「框选文字」，或点工具页的「框选文字」卡，然后用系统自带的框选界面框一块区域（Esc 取消，空格切换成选窗口）：区域里的文字在本机识别后直接复制到剪贴板，并记进剪贴板页（来源显示「框选文字」），刘海提示「已复制识别出的文字 · N 字」；没有文字时提示「没有识别到文字」。同一时间只做一轮：一轮没结束时再按快捷键不会开第二轮，往卡片上拖图片会提示「正在识别，请稍候」。截图不保存、不联网 |
| 框选文字的权限 | 需要「屏幕录制」权限。没开时面板里会出现说明卡：点「打开系统设置」，在 隐私与安全性 → 屏幕录制 里打开 ShelfU，然后**退出并重新打开 ShelfU** 才会生效，再按 `⌃⌥O` 即可。也可以用设置里的「系统权限」开关一起开（见「开启系统权限」）。ShelfU 不在启动时检查或申请这项权限 |
| 工具页 | 点顶栏左侧的「工具」图标：一页卡片网格，4 列排列，动作卡和小组件放在一起。全新安装默认是音乐 2×2、保持唤醒和 AI 用量各 1×1（AI 用量卡片要打开它的页面才出现）、最近文件和剪贴板最新各 2×1，后面是八张动作卡：框选文字、压缩到 1 MB、转成 PDF、打成 zip、转 JPEG、转 Word、解压、缩小图片；隔空投送等其余卡片在「+」打开的目录里。超过两行就在页内滚动 |
| 用动作卡 | 点按动作卡：对托盘里选中的、它能处理的项目执行（例如「转 JPEG」只处理选中的图片），结果和右键转换一样放进托盘最前面；没有合适的选中项时卡片轻摇并提示「把文件拖到这里」，转换任务正在进行时提示「一次只跑一个任务，请稍候」。也可以把文件直接拖到卡片上松开；「框选文字」卡接收图片，会识别图里的文字并复制 |
| 编辑工具页 | 长按任一卡片约半秒，或点页面动作行右边的铅笔图标，进入编辑：卡片轻轻摆动，拖动可以排序，点 ⊖ 移除，拖右下角的把手在卡片支持的尺寸之间切换（小组件是 1×1 / 2×1 / 2×2，动作卡固定 1×1），点虚线「+」格打开卡片目录添加（格子放满时「+」改到「完成」左边）。点「完成」或按 Esc 结束（在目录里按 Esc 只关目录）。布局存在数据文件夹的 `layout.json` 里 |
| 音乐卡片 | 音乐小组件默认 2×2，是完整的播放器：封面、歌名和「歌手 · 应用」、已播时间 + 可拖动的进度条 + 剩余时间、上一首 / 播放暂停 / 下一首、音量行。拖进度条松手后跳转，拖音量条松手后设置系统默认输出设备的音量；设备不能调音量时音量行变暗。2×1 保留封面、标题和播放暂停；1×1 只有封面和歌名，点一下切换播放。没有在播放时显示空状态 |
| 小组件的移动 | 旧版本放在「主页」的小组件在升级后第一次打开时按原尺寸搬进工具页的网格；最近文件和剪贴板最新卡片显示托盘里最近的文件和最新的一条剪贴板内容，AI 用量卡片显示剩余最少的那个工具 |
| 固定到桌面 | 编辑时把卡片或小组件拖出面板：出了面板会继续跟着光标显示，松开就变成桌面上的一张小浮窗，保留点按和接收文件；拖回面板里松开则放回原位。浮窗不会抢走你正在打字的应用的键盘焦点。拖动浮窗可以移动位置，也可以拖到另一块显示器上 |
| 贴边收起 | 把浮窗松在屏幕左右边缘 24pt 以内，它会收成一条贴边的窄条；鼠标移上去展开，移开 0.6 秒后收回；拖着文件靠近窄条 40pt 以内也会展开，可以直接放进去。同一边的多条会自动错开排列 |
| 浮窗的右键菜单 | 右键浮窗：「始终展开」（贴边的才有，不再自动收回）、「放回刘海」（小组件和动作卡都回到工具页原来的格子）、「从桌面移除」（卡片不回页面，可以再从目录加回来）。把浮窗拖到刘海正下方，刘海提示「松开放回」，松手也会放回 |
| 拖到刘海直接处理 | 拖着文件靠近刘海，面板直接打开「托盘」页；文件在面板上时，页面内容换成「放入托盘」宽格和按文件类型出现的最多 4 个动作格，顶部那一行写「投放」和数量：全是图片 →「压缩到 1 MB」「转成 PDF」（多张时「合成一个 PDF」）「转 JPEG」（全是 JPEG 时为「转 PNG」）「隔空投送」；全是 PDF →「转 Word」「每页存成图片」「打成 zip」「隔空投送」；全是压缩包 →「解压」「隔空投送」；其他文件或文件夹 →「打成 zip」「隔空投送」。松手在哪一格就执行哪一格，结果放进托盘最前面，原文件不放进托盘；隔空投送只打开系统面板。松在宽格或其他地方 = 放入托盘。已有转换任务在进行时，动作格暂时不可用 |
| 快速查看 | 选中文件或图片后按空格；再按空格或 Esc 关闭 |
| 转换图片 | 右键图片（截图、剪贴板图片，或拖进来的 jpg、png、heic、webp、tiff、gif、bmp、avif）→「转换为」：JPEG、HEIC、PNG（图片已经是哪种格式，那一项置灰）、PDF、Word（识别文字）。选中多张时是「转换 N 张为」，每张各转一份；另有「合并为一个 PDF」，按托盘里的顺序排页。选中里混有不是图片的项目时不出现这些选项 |
| 转换 PDF | 右键 PDF →「转换为」：「Word（提取文字）」或「PNG / JPEG（每页一张）」；选中多个时是「转换 N 个为」。转出的 Word 只有文字：PDF 的每一页对应 Word 的一页，原来的排版、表格、字体和图片不会带过去；扫描版的页面没有文字层，会先识别图里的文字。每页一张图片时按「名 第 2 页.png」命名，只有一页的 PDF 直接用原名。选中里同时有 PDF 和图片时不出现转换选项 |
| 转换的结果 | 转好的文件排在托盘最前面并已选中，直接拖出即可；图片左下角标出新格式。文件名沿用原名、只换扩展名，重名时加「 2」。原文件不会被改动。转好的文件存在 ShelfU 的数据文件夹里，在托盘里移除它，文件也一起删除——要长期保留请先拖到别处 |
| 图片转成 Word | 先放识别出的文字（按行分段，可以编辑），下面附上原图，纸张 A4。只还原文字内容，不还原表格、字体和排版；没识别到文字时只放原图，并提示「没有识别到文字」。第一次识别要准备文字识别模型，可能需要十几秒 |
| 转换进度与取消 | 识别文字、合并多张时，顶栏右侧出现一个小进度圈：鼠标停在上面看「正在转成 JPEG · 2/3」，点它出现「取消」，已经转好的会保留；某一张失败不影响其他张，完成后提示成功和失败各几项 |
| 缩小图片 | 右键图片 →「缩小图片」（多张时「缩小 N 张图片」）→ 大（长边 2560 像素）/ 中（1600）/ 小（800）。只缩小不放大：本来就比所选尺寸小的图片保持原尺寸；选中的图片都不超过某个尺寸时，那一项置灰。JPEG、PNG、HEIC 保持原格式，其他格式存成 JPEG；文件名加上尺寸，如「照片 1600px.jpg」。完成后提示缩小前后的总大小 |

面板与刘海融为一体：有刘海的 Mac 上纯黑的总览和面板从刘海里长出来、分不出边界；没有刘海的显示器上同样从顶部中央展开成一块黑色圆角面板。展开后的外观跟随系统：深色时纯黑，浅色时深色毛玻璃；打开「减少透明度」时一律纯黑；「减少动态效果」时切页只保留淡入淡出，不做位移。空闲时窗口贴在顶边且完全透明；只有画出来的黑色块接收鼠标，旁边的菜单栏照常可点，面板下面和两侧的应用也照常可点。

文字历史默认最多保留 **30 条文字**（设置… → 剪贴板 → 「保留条数」可改为 100 或 300 条，右键菜单栏图标 → 「剪贴板记录」同款选项），单条文字不限制长度。列表只显示简短摘要，单击复制或拖出时仍是完整正文。重复文字移到顶部，不新增重复项；文件和图片不占文字限额，也没有数量上限，不需要时手动移除即可。置顶的文字不占限额（不会被淘汰），两个标签页都把置顶项排在最前。

每条剪贴板记录会记住复制它的应用；右键剪贴板条目可以选择「不再记录来自该应用的内容」，该应用的标识符会写入 `settings.json` 的 `excludedApps`（不区分大小写）。想恢复记录，在 **设置… → 剪贴板 → 排除的应用** 里点该行的「移除」，或退出 ShelfU 后从 `settings.json` 里删掉它。

顶栏只有一行，被摄像头的刘海分成左右两耳：左边是页面图标——总览、托盘、剪贴板、工具，开了 AI 用量时再加一个「AI 用量」，这一行最多放五个图标（「正在播放」只在它是当前页时临时占一个位置）；右边是正在进行的事的小胶囊（最多两个）和设置按钮。当前页的图标下面有一个底色胶囊。鼠标停在图标上会显示名字，点一下就打开那一页；点总览的图标回到总览。没有「收起」按钮：点面板外面或按 Esc 就收起。

总览是 440 × 156，内容区 416 × 106：左边一列是两行状态字和下面的海獭，右边上面是「最近放入」的五项、「全部 ›」，下面是「当前最相关的事」那一行。页面是 440 × 250：上面是同一行顶栏（此刻左边多出正在进行的事的小胶囊，但总览页不显示这些胶囊），下面是页面自己的动作行，最右是这一页的按钮（例如托盘和剪贴板的「清空」、工具页的铅笔或「完成」、剪贴板页的搜索框）。面板切换尺寸时外壳向下长出或收回，切页时图标不动，只有底色胶囊滑到新图标上；面板在 240 毫秒里淡出旧页、淡入新页。内容区固定 416 × 174，内容多时在页内滚动：哪一侧还有内容，那一侧靠近边缘的几行就逐行虚化（剪贴板约 15pt、托盘和工具约 24pt），滚到头的那一侧不再虚化，完全不在边带里的行也不处理；切页的那 240 毫秒里暂停虚化。托盘页显示全部内容，剪贴板页只显示剪贴板收录的文字和图片。按 `⌃⌥V` 会直接打开剪贴板页并把焦点放进搜索框，全程不需要鼠标（这时整块面板会下移到菜单栏之下）；复制选中项后收起，并把焦点交还给你之前所在的应用。这个快捷键按下时 ShelfU 才会短暂获得键盘，其余打开方式（悬停、拖入、单击图标）一如既往不抢焦点。

当前页有未置顶的内容时，动作行右边会显示“清空”按钮：点击一次移除这一页里置顶以外的项目并立即生效，误清空不会弹确认框，请留意。剪贴板截图和复制的图片同时出现在托盘页和剪贴板页，清空（或右键「移除」）只把它移出当前这一页，另一页照常保留：在托盘页清空，剪贴板记录还在；在剪贴板页清空，托盘里的截图还在。已经从另一页移出的截图，再从这一页移除时才真正删除。剪贴板文字只在剪贴板页，在那里清空就是删除。再次复制同一内容，它会回到两页。置顶的项目连同 ShelfU 替它们保存的图片会保留下来；真正删除的项目会删除 ShelfU 自己保存在 `images/` 里的剪贴板图片与截图，但文件引用指向的原文件始终不会被删除；只想移除个别项目时，右键该项目 → 「移除」。

自动清理每小时检查一次，选择后立即执行一次。“超过 N 天”从项目最近一次放入托盘算起：同一内容再次复制或拖入会重新计时。清理与“清空”一样，只删除 ShelfU 自己保存的图片，绝不删除文件引用指向的原文件。

面板展开且你正在使用时，ShelfU 会临时占用空格键和 Esc（焦点在剪贴板搜索框时不占用，按键留给输入）；点一下其他应用就会归还。

文件拖入只记录路径，不复制原文件。原文件被移动或删除后，再打开托盘会标灰并显示“文件已移动”；可以手动移除该项。重启时会清理真正不存在的引用。

图片较多时会分批生成缩略图，相机照片会按照片记录的方向显示。再次复制同一张图片时，ShelfU 会检查已保存的内容；如果文件被改写或损坏，会用本次复制的原图恢复。

拖拽进入顶部接收区后如果没有放入内容，离开接收区或面板后会自动缩回刘海。悬停只显示探头提示（小箭头，或正在播放时的两翼），不会自行展开；单击提示或按快捷键唤出的面板会保持展开，直到你明确收起。个别应用的拖拽不经过系统拖拽剪贴板，刘海可能不会探头；这时按快捷键打开托盘再拖进去。

## 设置窗口

右键点菜单栏图标 → **设置…** 会打开一个普通窗口，把所有偏好集中在一处。窗口分成侧栏和内容两栏：侧栏按「通用 / 刘海 / 内容 / 系统」分组列出八个页面，底部显示系统权限的状态。窗口居中出现在光标所在显示器上，已经开着时再次打开只会把它调到最前，不会开出第二个。

侧栏底部的权限状态：全部开好时是一个绿点和「系统权限已全部开启」；还差几项时是一个橙点和「还差 N 项权限」。点这一行打开「系统权限」分页。

每个控件改完**立即生效**，和菜单栏子菜单调用的是同一套设置逻辑，所以两边永远不会不一致：在窗口里改完，菜单栏再打开时显示的就是新状态（反过来也一样）。内容超出窗口高度时窗口内部滚动；按 `Esc` 或 `⌘W` 关闭窗口。

**开机时自动启动**需要 `ShelfU.app` 在“应用程序”文件夹里：注册失败时（例如从别处直接运行开发版）原因会直接显示在开关下方，不会静默失败。开关状态每次打开窗口时都从系统重新读取，所以你在系统设置里手动改过也会如实显示。

**settings.json 损坏时**，每一页顶部都会显示红色提示条，说明设置已按默认值运行，并且所有偏好控件——语言、更新、刘海样式、实时活动、拖窗口分屏、托盘整理、剪贴板记录、AI 用量和快捷键页的全局快捷键——全部锁定（置灰、点不动），避免把坏文件覆盖成一份看似正常的默认设置；系统权限、关于页和只读的按键说明照常可用。修好文件后重新打开 ShelfU 即可恢复。

## 开机自动运行

1. 打开 **设置…**（右键菜单栏图标 → 设置…）。
2. 在「通用」里打开 **开机时自动启动**。
3. 下次登录后 ShelfU 会自动常驻菜单栏。

如果注册失败（窗口里会显示原因），可以用系统自带的方式手动添加，效果相同：

1. 确认 `ShelfU.app` 已经放在“应用程序”文件夹。
2. 打开 **系统设置 → 通用 → 登录项**（部分系统叫“登录项与扩展”）。
3. 在“登录时打开”的列表点击 **+**，选择 `ShelfU.app`。

## 自动更新

正式版 ShelfU 会自己检查新版本：启动后不久查一次，之后每天一次，查询对象是本项目在 GitHub 的**最新 Release**（`henryyu333/shelfu`）。如果你另外开启了 AI 用量页，它还会向 Codex 与 Claude Code 各自的官方地址查询套餐额度（见「数据与隐私」）。除此之外没有其他网络请求——更新检查是标准的 HTTPS GET，User-Agent 只写明应用名与版本（如 `MyGo/0.5.5 ShelfU/1.10.0`），不发送任何个人信息、设备标识或使用数据；更新包附带数字签名，安装前会验证签名与完整哈希，只有用发布方私钥签名的版本才会被装上。

发现新版本时不会有弹窗打扰：总览的「当前最相关的事」那一行出现提示，菜单栏图标的右键菜单里多出「安装更新（vX）…」。只有你选择它才会下载并替换应用；装好后菜单项变成「重新启动 ShelfU 完成更新」，总览那一行变成「新版本已就绪 · 重新启动」和「重新启动」按钮；重启后进入新版本（也可以直接退出再打开）。随时可以用右键菜单的「检查更新…」或 设置… → 通用 →「现在检查」手动查询。

不想让它联网检查：设置… → 通用 → 关闭「自动检查更新」，立即生效；也可以先退出 ShelfU，把 `settings.json` 里的 `"autoCheckUpdates"` 改成 `false` 再打开。关闭后手动检查仍然可用。开发构建（`go build`/`mygo dev` 的产物）不做检查，菜单里的检查会说明该构建未启用自动更新。

提醒：从 Shelf 换到 ShelfU 时，macOS 会要求把系统权限再开一次（设置… → 系统权限 的开关）。ShelfU 的正式发布版用固定签名，之后更新会保留授权；自己编译的构建每次签名都会变，可能要重新开启。

从 Shelf 升级：ShelfU 是 Shelf 的新名字。ShelfU 第一次打开时，会把 `~/Library/Application Support/Shelf/` 里保存的内容复制到 `~/Library/Application Support/ShelfU/`；旧文件夹保持原样，确认内容都在以后可以删掉。macOS 会把 ShelfU 当成一个新应用，所以系统权限和「开机时自动启动」要重新打开一次。

- 在 Shelf 里应用内更新：更新装好后，在“应用程序”里打开 Shelf。它会自己改名为 `ShelfU.app` 并以 ShelfU 打开。
- 用 ShelfU.dmg 安装：先退出 Shelf，把 `Shelf.app` 移到废纸篓，只让 ShelfU 使用你的内容。

## 数据与隐私

数据保存在：

```text
~/Library/Application Support/ShelfU/
  state.json        托盘内容（含图片清单）
  settings.json     设置
  layout.json       工具页的卡片和小组件排列、桌面固定项的位置（旧版本的文件打开时自动迁移：主页上的小组件搬进工具页；文件损坏时按默认布局显示，不会被覆盖）
  ui.json           总览里的欢迎卡和新版本介绍看过没有
  images/           剪贴板图片与截图
  .lock             防止同时运行两个 ShelfU 的锁文件，运行时不要删除
  usage-cache/      AI 用量页的本地用量统计缓存（开启过才有，删掉只是下次统计变慢）
```

在 Finder 按 `⌘⇧G`，粘贴 `~/Library/Application Support/ShelfU/`，即可找到它。备份时先退出 ShelfU，再复制整个文件夹；恢复时同样先退出。

剪贴板记录始终开启：复制的文字和截图都会自动收进 ShelfU。不想让某个应用里复制的内容被记录，右键它的剪贴板条目 →「不再记录来自『应用名』的内容」；临时不想记录某段内容，先退出 ShelfU 再复制。各种偏好都可以在设置窗口里改；它们存在 `settings.json` 里：`"clipboardLimit"`、`"retentionDays"`、`"excludedApps"`、`"autoCheckUpdates"`，正在播放开关对应 `"islandNowPlaying"`，拖出后从托盘移除对应 `"removeAfterDrag"`，AI 用量页的开关都在 `"aiUsage"` 里（默认 `enabled` 为 `false`，各来源开关默认 `true`）；除 `"retentionDays"`（默认 0，不清理）、`"clipboardLimit"`（默认 30）、`"removeAfterDrag"`（默认 `false`）与 `"aiUsage.enabled"` 外默认都是 `true`。四个全局快捷键在 `"shortcuts"` 里：`toggle`、`clipboard`、`capture`、`tray`，空字符串表示这一项没有快捷键。旧版本留下的 `"clipboardHistory"` 不再起作用，下次保存设置时会自动去掉。文件写错时，ShelfU 会提示并按默认设置运行，不会改动你的文件；此时设置窗口会锁定这几组控件，等你修好文件再改。

同一时间只能运行一个 ShelfU：再打开第二个时，它会提示“已在运行”并立即退出，不会影响已有内容。

**文字历史以明文保存，不提供加密。** 密码管理器标记为隐私的密码不会被记录，但其他复制的内容（验证码、客户资料等）都可能被收进历史。不希望某段内容被记录时，先退出 ShelfU 再复制。删除文件引用不会删除你的原文件；在剪贴板页移除剪贴板图片会清理 ShelfU 自己保存的图片（托盘页的移除只让它不再显示在托盘）。

ShelfU 不上传任何内容：没有云同步、遥测或统计。联网请求只有两类：向 GitHub Releases 的自动更新检查（见「自动更新」一节：默认开启，可在设置里关闭；请求不含个人信息），以及可选的 AI 用量页的额度查询。日常使用不需要任何授权。三项系统权限都可选，用设置… → 系统权限 的一个开关一起开：「完整磁盘访问」让从下载、桌面、文稿等文件夹拖入时不再弹窗；「辅助功能」用于刘海拖放保护，拖着内容靠近刘海时，指针会停在托盘接收区里，不会顶到屏幕最上沿；「屏幕录制」只给「框选文字」用（见下）。设置窗口里这一行写「已全部开启（3/3）」就说明都已生效。

**框选文字**需要「屏幕录制」授权，只在你使用它时才会提示。它只截取你框选的那一块区域，文字在本机识别后放进剪贴板，截图不保存、不上传。授权后要退出并重新打开 ShelfU 才生效。

**AI 用量页**默认关闭。打开后，Codex 的额度用本机保存的登录信息（`~/.codex/auth.json`）向 chatgpt.com 查询；Claude Code 的额度通过运行你装好的 Claude Code 的 `/usage` 命令读取，由 Claude Code 自己照常联系 Anthropic，ShelfU 只读钥匙串里的 Claude Code 凭据来判断账号和套餐。登录信息不会发给任何其他地方，ShelfU 也不会替你登录。最近一次查到的额度保存在数据文件夹的 `quotas.json`。「本机用量」只在这台电脑上读取 omp、Claude Code、Codex 的会话记录文件做汇总，统计结果不上传；每个来源都可以在设置里单独关掉。关掉总开关后页面消失，不会再有任何读取和查询。

如果保存的数据无法读取，ShelfU 会提示原因；确认后本次启动退出，不创建菜单栏托盘或占用快捷键，也不会用空内容覆盖原文件。请先备份数据文件夹再处理，然后重新打开 ShelfU。

## 卸载

1. 右键菜单栏图标 → 退出 ShelfU。
2. 把“应用程序”里的 ShelfU 移到废纸篓。
3. 如果连保存的内容也要删除，删掉 `~/Library/Application Support/ShelfU/` 文件夹。

## 修改快捷键与灵敏度

四个全局快捷键在 **设置… → 快捷键** 里改，不用重新打包：点一下那一行，按下新的组合键就保存并立即生效；Delete 清空这一项，Esc 取消。和其他应用或系统快捷键冲突时，这一行会显示「已被占用」，并保留原来的组合。默认是显示 / 收起 `⌃⌥Space`、剪贴板搜索 `⌃⌥V`、框选文字 `⌃⌥O`，「打开托盘」默认不设。Esc 和剪贴板里用来选择和复制的按键属于面板本身，不能改。

灵敏度（投放带、悬停余量、离开后多久收起）仍是编译期常量，要改需要改源码后自己重新打包（需要 Go 1.27 或以上以及 Xcode Command Line Tools）。

1. 下载本项目源码，用代码编辑器打开 `cmd/shelfu/config.go`。
2. 可以调整：`dropBandPadX`（投放带相对刘海的水平外扩，默认 24pt：触发带就是刘海宽度左右各加这么宽，刘海宽度至少按 180pt 计）、`guardDropPad`（投放带比菜单栏向下多出的高度，默认 16pt）、`notchHoverPadX` / `notchHoverPadY`（空手悬停刘海的感应余量，8×4 pt）、`edgeLeaveDelay`（离开后多久收起，350 毫秒）。
3. 在终端进入项目目录，运行：

```sh
go run github.com/egoist/mygo/cmd/mygo build
```

4. 打包好的 `ShelfU.app` 和 `.dmg` 在 `dist.noindex/darwin-arm64/` 里。先退出正在运行的 ShelfU，再用新的替换。
